# 双遍翻译与术语控制

## 翻译前

沿用用户目标语言、地区和风格要求。保留原作语气、时代语境、论证力度与叙述人称；不擅自现代化观点或加评论。标题和文件名可译成目标语言，来源标识保持稳定。

`译名表.md` 至少记录：原词、固定译法、首次位置、上下文/例外和决定状态。多义词按语境区分，不能全书机械替换。专名、作品、机构、技术词和缩写在翻译开始时建立初稿，随着正文更新。

章首可放追溯块（脚本只清理此类已识别的开头块）：

```markdown
# 第一章 {#ch-001}

原文标题：Original chapter title
来源文件：001_original.md
来源 EPUB：source/book.epub

---

这里开始正式正文。
```

正文中真实使用的分隔线应保留。其他格式的工作说明只存报告或状态文件，不混入正文。

## 第一遍：完整覆盖

逐章逐段翻译，保持结构顺序。篇幅大时按稳定段落 ID 或范围切块，给每块提供章标题、相邻上下文、术语表和必要人物关系。不要仅按字符数从句中截断，也不要重复翻译重叠上下文。

保留数字、年份、币种、单位、ISBN、引用、脚注和公式；表达可自然，但不能省略限定条件、否定、因果或不确定性。代码/API/URL/路径按其功能保留，不翻译成不可运行的标识。图表文字按可编辑性处理并记录，不能声称不可读图片已译。

缺失、模糊或损坏的源文标记位置并回查原 EPUB；不得凭上下文补造。未完成章保留部分状态，不把占位符写入已完成清单。每块落盘后记录覆盖范围及译稿哈希。

## 第二遍：实际对照

重新读取源文和对应译文，逐段核对：

1. 覆盖：无漏段、漏句、重复段或未经要求的摘要。
2. 含义：主客体、代词、否定、条件、因果、时态和语气强度正确。
3. 一致性：术语、人名、标题和跨章引用遵守已确认决定。
4. 细节：数字、计量、日期、书目、公式编号和注释准确。
5. 表达：目标语言自然，保持文体，不为流畅牺牲内容。
6. 结构：标题、表格、图片、代码、注释及回链仍可解析。

记录实际核对范围和修订结果，而不是写一句“已校对”。篇幅比例或机械词数只可作为异常线索，不能证明忠实度。未决术语/歧义单独列出；用户未要求时，不把编辑评论插入成品。

## 返工与交付

术语决定变更时检索受影响章，逐处核对，更新第二遍状态；不无条件批量替换。源章或译稿在校对后改变，原校对状态失效，需检查受影响范围并重建成品。只报告真实完成的范围，部分译本应清晰标注。
